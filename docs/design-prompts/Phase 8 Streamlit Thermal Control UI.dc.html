ZONE → STREAMLIT PRIMITIVE
A · Status strip — st.container(border=True) full-width, fixed height, colored via st.markdown(unsafe_allow_html); renders every rerun so height never collapses.
B · Chart — Altair/Plotly chart via st.altair_chart, sized to dominate the right column.
C/D/E · Left rail — st.columns + three st.container(border=True) cards; mode box uses fixed min-height CSS so switching modes doesn't resize the card.
F · Telemetry tiles — grid of st.columns, each holding one st.metric styled with CSS.
G · AI panel — its own st.container(border=True), conditionally rendered only in AI mode; sits below the chart so its appearance never shifts C–F.
H · Decision log — st.tabs(["Live","Decision Log"]) at the top of the right column; log itself is st.dataframe with a pandas Styler applying row background by result. All within reach: no custom JS, no fixed/sticky positioning.
