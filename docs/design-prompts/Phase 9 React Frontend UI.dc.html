Legend & component notes

SEVERITY COLOR
Green — nominal / allowed
Amber — degraded / warning
Red — critical, system-imposed (lockout, hard trip, AI fallback)
Red, squared — critical, operator-chosen (manual override) — same severity, different shape so it's never confused with a system-imposed trip
Gray — inactive / no data
Violet — connection state (orthogonal to safety severity, never reused for alerts)
IMPLIED PRIMITIVES (shadcn/ui + Tailwind + Radix)
Toolbar status pill — Radix Tooltip + a Tailwind pill; transitions with a CSS transition-colors/fade, never a hard swap.
Connection badge — polls WebSocket readyState; pulsing dot via a CSS keyframe, not JS-timed.
Toasts — shadcn Sonner/Toast for one-shot events (spike fired, lockout engaged); auto-dismiss, don't block the status pill.
Reset / Reset Interlock — two-stage button (shadcn Button swapping label+variant on first click) rather than a Radix AlertDialog modal — fast enough for a live demo, still has a confirm step.
Decision log row — new row mounts with a brief background-color transition (Framer Motion or a CSS @keyframes flash) rather than popping in.
AI reasoning panel — same DOM node/size in every mode; contents swap via conditional render inside, so neighbors never reflow.
Stale overlay — diagonal-stripe scrim (CSS repeating-linear-gradient) over chart + log, driven by a "seconds since last message" timer.
